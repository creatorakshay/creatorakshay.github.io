## 🚨 Risk Mitigation

### Potential Blockers

- **Blocker:** Time constraints (15h weeks too ambitious)
  - **Mitigation:** Stick to 8h weeks; use stretch weeks selectively
- **Blocker:** Difficulty with AI concepts
  - **Mitigation:** Use multiple resources; slow down if needed; get peer feedback
- **Blocker:** Can't complete certifications
  - **Mitigation:** Focus on portfolio + visibility instead; cert is nice-to-have
- **Blocker:** GitHub feels intimidating
  - **Mitigation:** Start simple; PoC code doesn't need to be perfect; focus on architecture
- **Blocker:** LinkedIn feels uncomfortable
  - **Mitigation:** Start with 1 post; focus on ideas, not personal branding
